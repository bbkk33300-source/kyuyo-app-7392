かんたん給与管理（Android向けWebアプリ）

【入っているもの】
- index.html：アプリ本体
- manifest.webmanifest / sw.js / icon.svg：ホーム画面追加・オフライン表示用

【重要】
このフォルダをスマホに保存してファイルを開くだけでは、ホーム画面アプリとしてのインストールはできません。
ホーム画面に追加するには、HTTPS対応のWebサーバーにこの4ファイルを置く必要があります（例：GitHub Pages、Netlifyなど）。

【Androidでの追加】
1. 公開したURLをChromeで開く
2. Chrome右上の「︙」を押す
3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ

【使い方】
1. 「スタッフ設定」で名前と時給を登録
2. 「勤務入力」で日付・スタッフ・出勤・退勤・休憩を入力
3. 「給与集計」で月の合計を確認
4. 「データ保存」で定期的にバックアップを書き出す

【計算について】
22:00〜翌5:00を深夜時間として時給1.25倍で計算します。
休憩は入力した分数を勤務の最後から差し引く簡易方式です。休憩の時刻を指定する機能はありません。
法定の休憩、時間外労働、法定休日、税・社会保険、交通費は別途確認してください。
データは端末のブラウザ内に保存されます。ブラウザのデータ削除や端末故障に備えてバックアップしてください。
