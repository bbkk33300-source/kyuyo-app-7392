かんたん給与管理 v5

更新内容
・正月手当／お盆手当／特別手当／交通費は1円以上の場合のみ給与明細に表示
・毎月26日～翌月25日を対象期間として、翌月分の給与に集計
・給与明細に店舗名、スタッフ名、対象月・対象期間を表示
・手当・交通費を「手当・特別設定」タブに集約（スタッフ別・給与月別）
・給与集計に控除額入力、差引支給額（手取り）を追加
・給与確定ボタンで月ごとの金額を固定し、対象勤務の追加・削除を防止
・勤務入力画面の勤務一覧から給与金額を非表示
・勤務入力以外のタブは店長用暗証番号を要求

更新手順
1. 既存データをアプリの「データ保存」からバックアップ
2. GitHub Pagesのリポジトリで index.html、sw.js、manifest.webmanifest、icon.svg を上書き
3. Commit changes
4. 公開ページを再読み込み。古い画面が残る場合はブラウザを再読み込み

注意
暗証番号は端末内のブラウザ保存データで照合する簡易ロックです。このアプリはブラウザ内だけで動くため、端末やブラウザの開発者機能を使える人への強固なアクセス制御ではありません。給与情報を厳密に保護する必要がある場合は、サーバー側ログイン機能が必要です。
データは端末のブラウザ内に保存されます。更新前に必ずバックアップしてください。
