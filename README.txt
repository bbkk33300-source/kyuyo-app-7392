かんたん給与管理アプリ v4

追加機能：月間シフトカレンダー
勤務入力で登録したスタッフ名・出勤時刻・退勤時刻を、月間カレンダーの日付欄に表示します。
給与集計、給与明細のまとめ印刷・個別コピー、スタッフ最大8名、バックアップ機能も含みます。

更新方法：GitHub Pagesのリポジトリに index.html、sw.js、manifest.webmanifest、icon.svg を上書きしてCommit changesしてください。
更新後は公開ページを再読み込みしてください。データ保護のため、更新前に「データ保存」からバックアップを取ってください。

データは端末のブラウザ内に保存されます。外部送信しません。
