かんたん給与管理アプリ v5（手当機能追加）

追加機能：スタッフごとの手当設定
スタッフ設定で、正月手当・お盆手当・特別手当をそれぞれ個別の金額で登録できます。各手当は毎月の給与に加算され、給与集計・印刷明細・コピー明細に内訳と合計を表示します。手当金額はバックアップデータにも含まれます。

既存のv4の勤務・スタッフデータは同じ保存領域を使うため、通常は引き継がれます。更新前に念のため「データ保存」からバックアップしてください。

更新方法：GitHub Pagesのリポジトリに index.html、sw.js、manifest.webmanifest、icon.svg を上書きしてCommit changesしてください。

手当はスタッフごとに設定した金額を毎月加算します。特定の月だけ支給したい場合は、その月だけ金額を設定し直してください。
データは端末のブラウザ内に保存され、外部送信しません。
