かんたん給与管理アプリ v5

追加機能：スタッフごとの手当設定
・初期の手当は「正月手当」「お盆手当」「特別手当」の3種類です。
・スタッフ設定で、支給する手当にチェックを入れ、金額を入力して保存します。
・「手当の種類を追加」から独自の手当名を追加できます（20文字以内）。
・給与集計と給与明細（印刷・コピー）に手当の内訳、手当合計、勤務給与との合計を表示します。
・手当の種類と各スタッフの金額は、端末内データおよびバックアップに保存されます。

既存のv4までの勤務記録・スタッフ設定はそのまま読み込みます。更新前に「データ保存」からバックアップを取ってください。

更新方法：GitHub Pagesのリポジトリに index.html、sw.js、manifest.webmanifest、icon.svg を上書きしてCommit changesしてください。公開ページを ?v=5 付きで開いて更新を確認してください。

データは端末のブラウザ内に保存されます。外部送信しません。
